# Practitioner quick start

1. Open Today and the visit.
2. Read the visit brief: clinic or mobile, the service address, access notes, allergies, contraindications, equipment, and whether consent is on file.
3. For a mobile visit, start travel from the visit actions. Start location sharing only for that trip. Stop it on arrival. The client does not receive your location history.
4. Write the SOAP note. Templates and chips are prompts. Dictate or type only what you observed or the client reported. Save the draft. Signing locks the note.
5. If a signed note needs a correction, record an amendment with a reason. The signed text stays.
6. Snippets you save are your own phrases. They are not applied to a chart on their own.
7. The visit shows the invoice and payment status. You do not confirm a card payment from the browser return page.

Your authenticator is optional until you enroll it. After enrollment, password sign-in waits for a code or a recovery code.
