# Nabitouch

Production-oriented mobile massage application for Emergent import. React and Vite are in `frontend/`. FastAPI and MongoDB are in `backend/`.

Read `EMERGENT_HANDOFF.md` before changing environment, data, or deployment. It records the source revision, the uncommitted work included here, and the files that were left out.

Local configuration starts from `backend/env.example` and `frontend/env.example`. Copy them to untracked env files and replace every placeholder. Do not point this import at production.
